# Varosha — Website Rebuild

Rebuild of [varosha.org](https://www.varosha.org/), the website of **Varosha**, a
registered 501(c)(3) nonprofit based in Palatine, Illinois. Varosha funds vocational
training, education, and micro-loans for women and children in West Bengal, India.

The current site is a Wix template site. This project replaces it with a custom,
professional, polished site that keeps every piece of real content and presents it
far better.

## Status

Phase 1 (audit of the existing site) is complete. Phase 2 (choose an aesthetic and
color palette) is waiting on a decision. See `PROGRESS.md`.
